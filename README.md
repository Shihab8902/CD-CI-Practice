# Starter

A modern React starter template bootstrapped with **Vite**, **TypeScript**, **Tailwind CSS v4**, and **React Router v7**.

Prepared by [Shihab Hasan](https://webdevshihab.netlify.app).

---

## What's Included

- ⚡ **Vite** — Fast dev server and build tool
- ⚛️ **React 19** — Latest React with concurrent features
- 🟦 **TypeScript 6** — Type-safe development
- 🎨 **Tailwind CSS v4** — Utility-first CSS framework
- 🧭 **React Router v7** — Installed, ready for routing
- 🔍 **ESLint** — Linting with typescript-eslint

## Getting Started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview

# Lint the codebase
npm run lint
```

## Project Structure

```
src/
├── App.tsx          # Root component with routing
├── main.tsx         # Entry point
└── index.css        # Global styles (Tailwind)
```

## Customize

Edit `src/App.tsx` to add your own pages and routes. All styles use Tailwind utility classes — no separate CSS files needed.
